## 📌 About This Repository

This repository contains the practical work, circuit designs, simulations, observations, and experimental results completed as part of the **Analog IC and Systems Laboratory (EEM512)** course during the 5th semester of B.Tech.

The primary objective of this laboratory is to develop practical understanding of semiconductor devices, analog electronic circuits, MOSFET-based amplifiers, current mirrors, differential amplifiers, active filters, and operational amplifier applications through circuit design and simulation.

The repository includes experiment-wise documentation, LTspice circuit files (`.asc`), laboratory reports (`.pdf`), simulation outputs, and supporting files wherever applicable.

## 🎯 Course Objectives

- Understand the electrical characteristics and behaviour of semiconductor devices.
- Perform DC operating point, DC sweep, transient, and AC frequency response analyses.
- Design and analyze BJT and MOSFET amplifier configurations.
- Extract and study MOSFET small-signal parameters.
- Understand current mirror circuits and their applications.
- Analyze differential amplifier configurations and their performance.
- Design and investigate active filters and operational amplifier circuits.
- Develop practical circuit simulation and analysis skills.

## 📚 Experiments

### Experiment No. 01 – Familiarization with Simulation Tools and Semiconductor Device Characteristics

**Objective:** Familiarization with simulation tools and study of basic semiconductor device characteristics.

**Topics Covered:**
- Operating Point Analysis (.op)
- DC Sweep Analysis (.dc)
- Transient Analysis (.tran)
- AC Analysis (.ac)
- RC Low-Pass and High-Pass Filters
- I-V Characteristics of Diode
- Input and Output Characteristics of BJT
- Transfer and Output Characteristics of MOSFET

### Experiment No. 02 – Design of CE, CB and CC Amplifier Stages

**Objective:** Design and analysis of Common Emitter (CE), Common Base (CB), and Common Collector (CC) BJT amplifier configurations.

**Topics Covered:**
- Common Base Amplifier
- Common Emitter Amplifier
- Common Collector Amplifier
- DC Operating Point Analysis
- Transient Response Analysis
- AC Frequency Response
- Voltage Gain and Current Gain
- Bandwidth Analysis
- Effect of Emitter Bypass Capacitor

### Experiment No. 03 – Extraction of MOSFET Small-Signal Parameters

**Objective:** Extraction of threshold voltage, intrinsic transconductance, and output resistance of NMOS and PMOS devices.

**Topics Covered:**
- NMOS and PMOS Characterization
- Threshold Voltage (Vth)
- Transconductance (gm)
- Output Resistance (ro)
- gm/Id Characteristics
- Analysis for Four Different Widths
- Width-Dependent Device Behaviour
- Small-Signal Parameter Extraction

### Experiment No. 04 – Design and Analysis of CS and CG Amplifiers

**Objective:** Design and analyze Common Source (CS) and Common Gate (CG) MOSFET amplifier configurations.

**Topics Covered:**
- Common Source Amplifier
- Common Gate Amplifier
- Voltage Gain Analysis
- Frequency Response
- Bandwidth Analysis
- Transistor-Based Amplifier Design

### Experiment No. 05 – Design of CS and CD Amplifiers

**Objective:** Design and analysis of Common Source (CS) and Common Drain (CD) amplifiers.

**Topics Covered:**
- Common Source Amplifier with Active Load
- PMOS Active Load
- Common Drain Amplifier
- Source Follower Configuration
- Source Follower with Load Resistance
- DC Operating Point Analysis
- Transient Analysis
- AC Analysis
- Voltage Gain and Loading Effects

### Experiment No. 06 – Design and Analysis of BJT and MOS Current Mirrors

**Objective:** Design and analyze BJT-based and MOSFET-based current mirror circuits.

**Topics Covered:**
- BJT Current Mirror
- MOS Current Mirror
- Reference and Output Current Analysis
- Current Copying Behaviour
- DC Operating Point Analysis
- Transient Analysis
- Current Matching and Branch Current Measurements

### Experiment No. 07 – Design and Analysis of Amplifiers with Current Mirror Loads

**Objective:** Design and analyze BJT Common Collector, MOSFET Common Source, and Common Drain amplifier configurations using current mirror loads.

**Topics Covered:**
- MOSFET Common Source with Current Mirror Load
- MOSFET Common Drain with Current Mirror Load
- BJT Common Collector with Current Mirror
- Biasing and Operating Point Analysis
- Transient Response
- AC Frequency Response
- Voltage Gain Analysis
- Current Distribution in Different Branches

### Experiment No. 08 – Design and Analysis of BJT and MOS Differential Amplifiers

**Objective:** Design and analyze differential amplifier configurations using BJT and MOSFET devices.

**Topics Covered:**
- BJT Differential Amplifiers
- MOSFET Differential Amplifiers
- Differential Mode Gain (Ad)
- Common Mode Gain (Acm)
- Common Mode Rejection Ratio (CMRR)
- DC Analysis
- Transient Analysis
- AC Analysis
- Comparison of Differential Amplifier Configurations

### Experiment No. 09 – Design and Analysis of Active Filters Using Discrete Op-Amp

**Objective:** Design and analyze active Low-Pass, High-Pass, and Band-Pass filters using discrete operational amplifier circuits.

**Topics Covered:**
- Active Low-Pass Filter
- Active High-Pass Filter
- Active Band-Pass Filter
- Pulse Input Response
- Sinusoidal Input Response
- Transient Analysis
- AC Analysis
- Bode Plot
- Nyquist Plot
- Frequency Selection and Attenuation Characteristics

### Experiment No. 10 – Design and Analysis of Integrator and Differentiator Circuits

**Objective:** Design and analyze integrator and differentiator circuits using discrete operational amplifiers for different pulse input frequencies.

**Topics Covered:**
- Op-Amp Integrator
- Op-Amp Differentiator
- Response at 100 Hz
- Response at 1 kHz
- Response at 50 kHz
- Transient Response Analysis
- Frequency-Dependent Behaviour
- Slew Rate and Bandwidth Limitations
- Circuit Compensation and Stability
